Frequently Asked Questions

What algorithms are available?
VTA (most precise, slowest), RTA (balanced), CHA (fast, less precise), Static (fastest, direct calls only)
What is a CVE vs Go CVE ID?
CVE-YYYY-NNNNN is the standard ID. GO-YYYY-NNNN is Go's own advisory ID. Both are accepted.
Do I need Library/Symbol/Fix Version?
Only if bypassing CVE lookup. All three must be provided together.
Does this tool modify my repository?
No. It clones a read-only copy for analysis. Your source code is never changed.
How long does a scan take?
Typically 2-10 minutes depending on repository size and algorithm chosen.
What does the call graph analysis do?
It traces whether vulnerable symbols are actually reachable from your code's entry points, reducing false positives.
